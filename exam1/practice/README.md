# Coding practice

Open a starter file, replace its `pass  # TODO` lines, and run its tests. Keep the
filenames unchanged. The [main README](../../README.md#run-your-tests) has commands
that work from this folder, the repository root, or its parent.

Complete [sorting functions](p3_sorts.py) before [sorting methods](p4_sortable_list.py),
and [MinHeap](p5_min_heap.py) before the [triage queue](p6_triage_queue.py). For heap
work, the [coding checkpoints](../study_paths.md#coding-checkpoints) divide Problem 5
into stages.

If stuck, inspect the relevant test and try a [hint](../hints.md). The
[main README](../../README.md#coding-practice) links each reference answer.
